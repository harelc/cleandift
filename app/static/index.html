How does this work?

The model

CleanDIFT (Stracke et al., CVPR 2025 oral) fine-tunes a Stable Diffusion 2.1 U-Net so that it produces meaningful semantic features directly from clean images — no noise injection, no timestep sweep. The U-Net is run once at t = 261 on the VAE-encoded clean image and we tap an internal up-block.

Feature extraction

  • Each uploaded image is resized to 768 × 768 and pushed through the model.
  • We read the us6 activation by default — a (1280, 48, 48) tensor on GPU. That's a 1280-D semantic descriptor for each of 2304 spatial cells, each roughly covering a 16 × 16 patch of the input.
  • Features are computed once per (image, caption, feature-key) and cached on the GPU.

Click-to-match

  1. Your click in the source image is mapped to a feature-grid cell (fx, fy).
  2. We L2-normalize all features and compute cosine similarity of the source descriptor against every target cell.
  3. The argmax cell becomes the predicted match; we render a coloured similarity heatmap over the target so you can also see ambiguity / multimodality.

Top-N correspondences

We compute the full 2304 × 2304 cosine-similarity matrix between source and target. A match is kept only if it is a mutual nearest neighbour (source's best target points back at the source), then we rank by similarity and apply NMS in source-grid space using the NMS radius slider. Lower radius → more matches packed close together; higher radius → fewer, more spread-out matches.

Salient region restriction

When Salient region only is on, we run a salient-object detector (rembg's isnet-general-use ISNet variant) on a 2×-downsampled copy of each image and threshold the resulting alpha mask. The similarity matrix is then masked on both sides before any argmax, so mutual nearest neighbours are computed only between foreground cells. Top-up one-way matches kick in if the mutual pool can't reach N.

Horizontal flip

The ↔ button next to each pane mirrors the image server-side and clears the cached features and saliency mask — so the next match request runs the full CleanDIFT pipeline on the flipped pixels. Useful when an object faces the opposite direction in the two images.

Where the compute lives

The Stable Diffusion U-Net (~1.3 B params) and the ISNet saliency model both run on a remote NVIDIA H100. This browser only talks to a FastAPI server over JSON; nothing is computed locally.

Tips

  • Drop different feature keys to trade resolution for semantics — us4–us6 are 48×48 (coarser, more semantic), us7–us9 are 96×96 (finer, more textural).
  • Setting a relevant caption (e.g. "a photo of a dog") slightly conditions the U-Net via the SD text encoder and can sharpen the features for that category.
  • First match per fresh image takes ~10–40 s (feature extraction); subsequent calls on the same image are near-instant since features are cached on the GPU.
